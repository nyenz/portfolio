# The Descent — Nyende David

An interactive portfolio: scroll to dive from the sunlit surface to the abyss, 4,000 m down.
Built with Three.js, Lenis and GSAP. Live at **https://nyenz.github.io/portfolio/**.

```
npm install
npm run dev        # local preview
npm run build      # production build in dist/
```

Add `?skipintro` to the URL to skip the loader, or `?q=low` to test the low-quality mode.
